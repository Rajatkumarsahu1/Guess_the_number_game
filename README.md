🎯 Advanced Number Guessing Game

An interactive and fun number guessing game built using Streamlit. Test your intuition, improve your guessing strategy, and challenge yourself across different difficulty levels!

🚀 Features
🎚️ Multiple difficulty levels:
Easy (1–50) → 10 attempts
Medium (1–100) → 5 attempts
Hard (1–200) → 3 attempts
🎯 Real-time score tracking
🔥 “Warmer / Colder” hints
💡 Dynamic hint range (low–high guidance)
📊 Guess history table
🏆 High score tracking
🔄 Restart / Play again functionality
🎉 Visual feedback (balloons on win!)
🖥️ Demo

Run locally to experience the game:

streamlit run app.py
📦 Installation
Clone the repository:
git clone https://github.com/your-username/number-guessing-game.git
cd number-guessing-game
Install dependencies:
pip install -r requirements.txt
Run the app:
streamlit run app.py

🎮 How to Play
Select a difficulty level
Enter your guess
Use hints like:
📉 Too Low / 📈 Too High
🔥 Warmer / ❄️ Colder
Try to guess the correct number within limited attempts
Beat your high score!
